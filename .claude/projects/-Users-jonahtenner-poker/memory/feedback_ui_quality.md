name: UI quality standards
description: User expects polished, professional poker table UI - not placeholder-quality
type: feedback
---

Never ship ugly or placeholder-quality UI. The poker table must look like a real online poker room (PokerStars/Full Tilt quality).

**Why:** User was very disappointed with the initial table UI quality - called it "a disgrace". They expect professional polish.

**How to apply:** When building UI components, especially the poker table, ensure: proper spacing, large readable card emojis, clear dealer/blind indicators, visible pot and buy-in totals, polished visual design with proper poker theming. Don't use tiny text or cramped layouts.
